# AI answer regression verification

The initial regression run failed because the prompt had no spatial priority, the request contained only one image, and the Markdown renderer did not exist. RED checkpoint: `229bd7a`.

Implemented a local-first request (approximate 80/20 analysis priority), labelled current-display context, exact marker coordinates within the crop, sanitized Markdown, and separate answer windows with explicit copy/close controls and no dismissal timer. The security-review checklist informed the HTML allowlist, blocked remote resources/navigation, and main-frame authorization for answer IPC.

Validation on macOS 12.7.5 Intel / Electron 37.10.3:

- `npm run typecheck`: passed.
- `npm test -- --maxWorkers=2 --testTimeout=20000`: 48 files passed; 726 tests passed, 1 skipped. An earlier concurrent-build run hit the existing 5-second relay signature stress-test timeout; the bounded rerun passed.
- `npm run build`: passed.
- Real Electron production-page smoke test: headings, lists, fenced code and tables rendered; scripts/images removed; window remained visible beyond 6 seconds; copying preserved original Markdown; the close button destroyed the window.
- Unit lifecycle tests advance 120 seconds and confirm each answer remains open until closed, and closing one does not remove another. Unauthorized senders/frames cannot read or copy answers.

The smoke test uses a deterministic model-response fixture, without uploading desktop data. This validates the display path, not a fresh live provider round trip. The approximate priority is prompt guidance, not a guaranteed numerical model attention weight. Windows and packaged arm64 builds were not executed on this machine.
