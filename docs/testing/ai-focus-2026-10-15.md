# PingForAI：任务模板、局部范围与展示页验证

环境：macOS 12.7.5 Intel、Node.js 22.14.0、兼容运行时 Electron 37.10.3。桌面验证使用构建产物；开发启动脚本要求 Node.js 22.16+。未执行 Windows、arm64 安装包或代码签名验证。

## 功能与验证依据

| 改动 | 验证 |
| --- | --- |
| 四种中英任务模板 | 模板内容与语言测试；真实设置页点击模板，确认仅对应信号提示词更新且动作保持不变 |
| 默认只上传局部；三档范围 | 测试默认值、旧设置归一化、范围保存、边缘裁剪、小屏幕限制及信号坐标 |
| 可选当前显示器背景 | 关闭时不生成背景图，请求只有一张图片；开启后发送第二张图片，并限制宽度且不放大小图；真实开关保存验证 |
| 请求防重 | 冷却设为零仍阻止并发上传；失败后解除锁并可重试 |
| 持续保留的 Markdown 回答 | 真实 Electron 页面检查标题、列表、代码块、表格、安全过滤、复制原文、手动关闭及超过 6 秒后窗口仍可见 |
| 独立交互展示页 | DOM 回归覆盖四个任务、首次提问、背景切换与缺失节点；真实浏览器切换任务和背景；390px 无横向溢出，1280px 桌面布局检查，控制台无错误 |
| 设置布局与密钥边界 | 真实窗口 720px / 980px 下 11 个信号区块均无重叠或溢出；密钥输入存在，公开配置只包含密钥状态，不包含密钥值 |

设置页验证使用临时模板/开关变更，结束后恢复偏好并等待落盘。测试不打印密钥。

## 验证边界

本轮使用模拟网络响应和预设页面内容，不上传真实桌面、不产生新的服务商 API 调用。验证请求结构、裁剪、锁、设置及显示行为，不保证任何具体模型的视觉能力或回答质量。80/20 是开启背景后的提示词优先级，不能强制模型的实际注意力权重。展示页回答明确标注为模拟，不作为真实调用记录。
